Equazioni Goniometriche

Risolvi equazioni dove l'incognita compare nell'argomento di funzioni seno, coseno e tangente.

Definizione: Un'equazione si dice goniometrica se l'incognita compare nell'argomento di una funzione goniometrica.

Equazioni elementari: $$\sin x = p, \quad \cos x = q, \quad \tan x = h, \quad \text{con } p, q, h \in \mathbb{R}$$

1. Equazioni riconducibili a elementari

Formula fondamentale della trigonometria ▼
$$\sin^2 x + \cos^2 x = 1$$
Formule di addizione ▼
$$\sin(\alpha+\beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta$$ $$\cos(\alpha+\beta) = \cos\alpha\cos\beta - \sin\alpha\sin\beta$$ $$\tan(\alpha+\beta) = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}$$
Formule di duplicazione ▼
$$\sin 2\alpha = 2\sin\alpha\cos\alpha$$ $$\cos 2\alpha = \cos^2\alpha - \sin^2\alpha$$ $$\tan 2\alpha = \frac{2\tan\alpha}{1-\tan^2\alpha}$$

Esempio 1: Sostituzione e equazione di 2° grado

$$2\cos^2 x - 3\cos x + 1 = 0$$

Usiamo la sostituzione $t = \cos x$:

$$2t^2 - 3t + 1 = 0$$

Le soluzioni sono: $t_1 = 1$ e $t_2 = \dfrac{1}{2}$

  • $\cos x = 1 \Rightarrow x = 2k\pi$
  • $\cos x = \dfrac{1}{2} \Rightarrow x = \pm\dfrac{\pi}{3} + 2k\pi$

2. Equazioni lineari in seno e coseno

$$a\sin x + b\cos x + c = 0 \quad (a \neq 0, \, b \neq 0)$$

Metodo dell'angolo aggiunto

Una combinazione lineare di seno e coseno può essere riscritta come:

$$a\sin x + b\cos x = A\sin(x + \varphi)$$

dove $A = \sqrt{a^2 + b^2}$ e $\tan\varphi = \dfrac{b}{a}$

Esempio 2: Angolo aggiunto

$$\sqrt{3}\sin x - \cos x - 1 = 0$$

Trasformiamo usando il metodo dell'angolo aggiunto:

$$\sqrt{3}\sin x - \cos x = 1$$ $$2\left(\frac{\sqrt{3}}{2}\sin x - \frac{1}{2}\cos x\right) = 1$$ $$2\sin\left(x - \frac{\pi}{6}\right) = 1$$ $$\sin\left(x - \frac{\pi}{6}\right) = \frac{1}{2}$$

Soluzioni: $x = \dfrac{\pi}{3} + 2k\pi$ oppure $x = \pi + 2k\pi$

3. Equazioni omogenee di secondo grado

$$a\sin^2 x + b\sin x\cos x + c\cos^2 x = 0$$

Se $\cos x \neq 0$, dividiamo per $\cos^2 x$ e otteniamo un'equazione in $\tan x$:

$$a\tan^2 x + b\tan x + c = 0$$

Esempio 3: Equazione omogenea

$$\sin^2 x - 3\sqrt{3}\sin x\cos x + 6\cos^2 x = 0$$

Dividiamo per $\cos^2 x$:

$$\tan^2 x - 3\sqrt{3}\tan x + 6 = 0$$

Soluzioni: $\tan x = \sqrt{3}$ oppure $\tan x = 2\sqrt{3}$

  • $x = \dfrac{\pi}{3} + k\pi$
  • $x = \arctan(2\sqrt{3}) + k\pi$

Riepilogo

Strategie risolutive:
  1. Sostituzione: Se compare una sola funzione goniometrica (es. $t = \sin x$)
  2. Angolo aggiunto: Per combinazioni di seno e coseno
  3. Formule goniometriche: Per ridurre a forme elementari
  4. Divisione per $\cos^2 x$: Per equazioni omogenee
