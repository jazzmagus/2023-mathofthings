Equazioni Goniometriche

Risolvi equazioni dove l'incognita compare nell'argomento di funzioni seno, coseno e tangente.

Definizione

Un'equazione si dice goniometrica se l'incognita compare nell'argomento di una funzione goniometrica.

Equazioni elementari:

\[\sin x = p, \quad \cos x = q, \quad \tan x = h, \quad \text{con } p, q, h \in \mathbb{R}\]

Equazioni riconducibili a elementari

Formule di riferimento

Relazione fondamentale ▼
\[\sin^2 x + \cos^2 x = 1\]
Formule di addizione ▼
\[\begin{aligned} \sin(\alpha+\beta) &= \sin\alpha\cos\beta + \cos\alpha\sin\beta \\ \cos(\alpha+\beta) &= \cos\alpha\cos\beta - \sin\alpha\sin\beta \\ \tan(\alpha+\beta) &= \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta} \end{aligned}\]
Formule di duplicazione ▼
\[\begin{aligned} \sin 2\alpha &= 2\sin\alpha\cos\alpha \\ \cos 2\alpha &= \cos^2\alpha - \sin^2\alpha \\ \tan 2\alpha &= \frac{2\tan\alpha}{1-\tan^2\alpha} \end{aligned}\]

Esempi risvolti

Esempio 1

Equazione:

\[2\cos^2 x - 3\cos x + 1 = 0\]

Soluzione: Usiamo la sostituzione \(t = \cos x\):

\[2t^2 - 3t + 1 = 0 \quad \Rightarrow \quad t_1 = 1, \quad t_2 = \frac{1}{2}\]

Risultato:

  • \(\cos x = 1 \Rightarrow x = 2k\pi\)
  • \(\cos x = \dfrac{1}{2} \Rightarrow x = \pm\dfrac{\pi}{3} + 2k\pi\)

Equazioni lineari in seno e coseno

Forma Generale
\[a\sin x + b\cos x + c = 0 \quad (a \neq 0, \, b \neq 0)\]

Metodo dell'angolo aggiunto

Una combinazione lineare di seno e coseno può essere riscritta come:

\[a\sin x + b\cos x = A\sin(x + \varphi)\]

dove \(A = \sqrt{a^2 + b^2}\) e \(\tan\varphi = \dfrac{b}{a}\)

Esempio 2

Equazione:

\[\sqrt{3}\sin x - \cos x - 1 = 0\]

Trasformazione:

\[\begin{aligned} &\sqrt{3}\sin x - \cos x = 1 \\ &2\sin\left(x - \frac{\pi}{6}\right) = 1 \\ &\sin\left(x - \frac{\pi}{6}\right) = \frac{1}{2} \end{aligned}\]

Soluzioni: \(x = \dfrac{\pi}{3} + 2k\pi\) oppure \(x = \pi + 2k\pi\)

Equazioni omogenee di secondo grado

Forma Generale
\[a\sin^2 x + b\sin x\cos x + c\cos^2 x = 0\]

Se \(\cos x \neq 0\), dividiamo per \(\cos^2 x\) e otteniamo un'equazione in \(\tan x\):

\[a\tan^2 x + b\tan x + c = 0\]
Esempio 3

Equazione:

\[\sin^2 x - 3\sqrt{3}\sin x\cos x + 6\cos^2 x = 0\]

Dividiamo per \(\cos^2 x\):

\[\tan^2 x - 3\sqrt{3}\tan x + 6 = 0\]

Soluzioni:

  • \(\tan x = \sqrt{3} \Rightarrow x = \dfrac{\pi}{3} + k\pi\)
  • \(\tan x = 2\sqrt{3} \Rightarrow x = \arctan(2\sqrt{3}) + k\pi\)
